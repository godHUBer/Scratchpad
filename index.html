The app bundle did not load

This page was served as raw source instead of the compiled app. That happens when Settings → Pages → Source is set to Deploy from a branch with a branch that stores source code.

Fix it in two steps:

  1. Add .github/workflows/deploy.yml (it ships in deployment/workflows/).
  2. Set Pages → Source to GitHub Actions, then re-run the workflow.

Details: README sections 4.1 and 4.2.
